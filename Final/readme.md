# Service Requests

Веб-додаток для роботи із сервісними заявками на React і TypeScript.

## Запуск

1. Встановіть Node.js.
2. Відкрийте папку проєкту в терміналі.
3. Виконайте команди:

```bash
npm install
npm run dev
```

Відкрийте адресу, яку покаже Vite у терміналі.

## Тестові акаунти

- Користувач: `user@example.com` / `user123`
- Оператор: `operator@example.com` / `operator123`

## Перевірка

```bash
npm run build
npm test
```

## Технології

- React і TypeScript
- React Router
- Axios
- TanStack Query
- React Hook Form і Zod
- Mock Service Worker (MSW)
- Vitest і React Testing Library
